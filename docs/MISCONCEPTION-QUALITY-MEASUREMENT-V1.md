# Misconception Quality Measurement v1

Admin kalite raporu uzman kararlarını ders, konu ve soru türü bazında toplar. Yanlış pozitif oranı `reddedilen aday / (doğrulanan + reddedilen aday)` olarak hesaplanır; henüz karara bağlanmamış adaylar ölçüme dahil edilmez.

Teknik `ai_distractor` etiketi raporda kullanıcıya gösterilmez. Geçmiş Learning Event kanıtı korunur; ölçüm görünümü yalnız özet üretir.
